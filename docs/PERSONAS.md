- 작성: 2026-10-14
- 용도: 남은 결정과 화면 설계의 기준입니다. 판단이 애매하면 아래 세 질문으로 정합니다.
  1. 주 페르소나 **민서**가 헷갈리지 않는가
  2. 실무자 **준호**가 믿고 쓸 수 있는가
  3. 운영자 **태인**이 혼자 감당할 수 있는가
- 기존 Figma의 페르소나(한지우)는 이 문서로 대체합니다.
- 공개 저장소에서 확인할 수 있는 결정과 기능 범위는 [고도화 방향](./RENEWAL.md)에 정리합니다. 초기 Figma와의 차이도 해당 문서에서 설명합니다.

## 1. 정민서 — 주 페르소나

**기본 정보**

- 34세, 판교 IT 회사 서비스 기획자, 서울 거주
- 투자 6년차. 국내 70% · 미국 30%. 매매는 증권사 앱으로 함
- 차트는 이동평균선 정도만 봄. 재무제표는 잘 안 봄

**투자 방식**

- 뉴스, 유튜브, 커뮤니티에서 테마(HBM, 2차전지, 원전 등)를 접함 → 관련 종목을 찾음 → 몇 주에서 몇 달 보유
- "관심이 몰리기 시작할 때"를 알아채는 게 수익의 핵심이라고 믿음

**지금 하는 방법**

- 네이버 데이터랩에서 키워드 검색량을 보고, 증권 앱에서 주가 차트를 따로 열어 눈대중으로 겹쳐 봄
- 보고 있는 테마와 종목은 메모 앱에 적어 둠

**사용 패턴**

- 평일 퇴근 후 21~23시에 PC로 20~30분 (주 2~3회)
- 출근길 지하철에서 모바일로 5분 (거의 매일)
- 주말 오전에 1시간 정리

**저장 규모:** 키워드 10~15개, 종목 15~20개, 카드(쌍) 30개 안팎. 해외 종목 5개 내외, 해외 키워드 1~2개

**목표**

1. 관심이 커지는 테마를 빨리 알아채기
2. 그 테마와 실제로 같이 움직인 종목 고르기
3. 내가 보는 것들이 이번 주 어떻게 바뀌었는지 1분 안에 확인하기

**불편**

- 두 사이트를 오가며 비교해야 함
- "같이 움직였다"는 근거가 없음
- 매번 다시 검색해야 함
- 모바일에서 차트 보기가 불편함

**바라는 것**

- 저장해 두면 알아서 갱신됨
- 한 화면에 겹쳐 보기
- 관계를 한 문장으로 알려 줌
- 주 1회 요약을 받음

**싫어하는 것:** 복잡한 설정, 같은 걸 다시 입력하기, 광고

**대표 시나리오**

1. 월요일 아침, 주간 요약 메일에서 "HBM 관심 급등 · SK하이닉스는 13주 평균보다 아래"를 봄
2. 퇴근 후 PC로 "HBM × SK하이닉스" 카드를 열고 기간을 1년으로 바꿈
3. 함께 보기로 한미반도체를 붙여 비교함
4. "관계 높은 종목 찾기"로 후보를 보고 2개를 내 키워드에 저장함

## 2. 박준호 — 보조 페르소나 (실무자)

**기본 정보**

- 39세, 증권사 리서치센터 소비재·인터넷 섹터 RA(리서치 어시스턴트) 8년차
- 회사에 유료 금융 단말이 있지만, 국내 검색 관심도 데이터는 없음

**하는 일:** 신제품과 브랜드의 검색량을 실적보다 앞서 움직이는 지표(대체 데이터)로 확인함. 보고서에 들어갈 차트와 수치 근거가 필요함

**사용 패턴:** 업무 시간에 27인치 와이드 모니터로, 주 3~4회, 한 번에 30~60분. 키보드를 많이 씀

**저장 규모:** 키워드 25~30개(브랜드·제품명, 네이버 성별·연령 조건 활용), 종목 20개

**목표**

1. 검색량이 주가보다 먼저 움직였는지 통계로 확인하기
2. 정확한 기간으로 비교하기 (예: 신제품 출시일 이후)
3. 동료와 팀장에게 근거를 공유하기

**불편**

- 수작업 비교에 시간이 많이 듦
- 통계 근거 없이 "AI 예측"을 내세우는 서비스를 믿지 않음
- 기간을 마우스로만 고르게 하는 화면이 답답함

**바라는 것**

- 날짜를 직접 입력하기
- 52주 YoY, 13주 이동평균, 13주선 괴리
- 판정 근거(시차, 표본 수, 신뢰도)
- PNG 내보내기와 링크 공유
- 출처 표기

**대표 시나리오**

1. 화요일 오전, 화장품 브랜드 키워드(네이버 20대 여성 조건) 카드를 엶
2. 기간에 `20250301`~`20250930`을 입력함
3. 함께 보기로 경쟁사 종목 2개를 붙이고 나눠 보기로 봄
4. "관심도가 오르면 2주 뒤 주가도 올랐어요 · 뚜렷함"을 확인하고 근거를 펼쳐 봄
5. PNG로 내보내 보고서에 첨부하고, 링크를 팀 메신저에 공유함

## 3. 김소연 — 입문 페르소나

**기본 정보**

- 27세, 마케팅 회사 2년차, 투자 1년차
- 미국 대형주와 국내 ETF에 소액 투자. 유튜브로 공부함

**사용 패턴:** 거의 모바일. 자기 전 10분, 주 2~3회

**목표**

1. 종목이 왜 올랐는지 이해하기
2. 무엇부터 봐야 할지 시작점 찾기

**불편**

- 용어와 차트가 어려움
- 무엇을 검색해야 할지 모름

**바라는 것**

- 쉬운 말
- 시작할 거리(요즘 많이 보는 키워드)
- AI가 관련 키워드를 찾아 주기
- 첫 방문 안내

**위험:** 관계를 예측으로 오해할 수 있음. 그래서 문장은 과거형으로 쓰고, "예측이 아니에요"를 알기 쉽게 밝힘

**대표 시나리오**

1. 친구 추천으로 카카오 로그인을 함
2. 홈의 "요즘 많이 보는 키워드"에서 '엔비디아'를 누름
3. 엔비디아 화면에서 "관계 높은 키워드 찾기"를 함
4. 'AI 반도체'를 저장하고 카드 문장을 읽음

## 4. 엄태인 — 운영자 페르소나

**기본 정보:** 1인 개발·운영자. 낮에는 다른 일을 하고, 운영은 저녁과 주말에 함. 장애를 실시간으로 못 볼 때가 많음

**목표**

- 누구나 가입하는 공개 서비스로 실제 운영하기
- MSA와 인프라(쿠버네티스, GitOps, 관측)를 깊게 경험하기
- 이력서에 설명할 수 있는 구조로 만들기

**제약**

- 비용 최소. 서버비는 감수하지만, 외부 데이터는 무료 한도 안에서
- 혼자 감당할 수 있는 운영 복잡도

**필요한 것**

- 자동 복구
- 휴대폰 알림
- 한도·비용 상한
- 한눈에 보는 운영 화면
- 코드로 다시 만들 수 있는 인프라

**판단 기준**

- "새벽 3시에 내가 안 일어나도 서비스가 버티나"
- "같은 걸 처음부터 다시 만들 수 있나"
- "이 선택의 이유를 면접에서 설명할 수 있나"

## 6. 페르소나에서 나온 설계 원칙

1. **근거 우선, 예측 금지** (준호의 신뢰, 소연의 오해 방지): 과거형 문장, 판정 라벨, 근거 펼쳐 보기
2. **쉽게 보이고, 깊이는 펼쳐서** (소연 ↔ 준호): 기본은 한 문장과 한 차트, 통계 세부는 펼쳐야 보임
3. **PC에서 분석, 모바일에서 확인** (민서): 모바일도 모든 기능이 되지만, 카드 목록·주간 변화·상세 확인을 가장 편하게
4. **저장해 두면 알아서** (민서): 자동 갱신, 주간 요약 메일, 수동 최신화 없음
5. **혼자 운영 가능** (태인): 자동 복구, 휴대폰 알림, 비용 상한, 관리 기능은 최소
6. **데이터 약관 준수**: 관심도가 나오는 화면에는 광고·유료화 없음, 원값 내보내기 제한, 출처 표기
