# UI-4 표시 규칙 구현

이슈: https://github.com/eom-tae-in/stock-insight/issues/34
브랜치: `feat/34/display-insights`

## 변경 범위

화면을 직접 변경하지 않고 UI-5 이후의 표시용 순수 함수를 추가한다.
대표 분석 선택, 관심도 값·전주 차이·YoY·최근52점, 급등·둔화 판정,
종목 KPI·13주선 괴리, 연결 키워드와 브리핑 우선순위, 미갱신·완료 주를 제공한다.
각 파일은 분석 선택·종목 지표·키워드 요약·날짜·브리핑 중 하나를 소유한다.
기존 계산·API·인증·DB·services·클라우드 구성은 변경하지 않는다.

## 검증

`npx vitest run src/lib/insights/insights.test.ts`: 15개 테스트 통과.
임계값 포함 여부,13·65주 결측,0과 결측 구분, 정렬 우선순위,
비교 종목 null 가격 제외, 티커 대소문자, 연결 분석의 값,
외 N, 최대3개, 빈 통계,14일 경계, 월요일과 ISO 연도 경계를 확인했다.

`npm run check`: 타입·린트·포맷과97개 파일631개 테스트 통과.
`WEB_AUTH_MODE=oidc npm run build`: 컴파일·타입·18개 정적 페이지 생성 통과.
`git diff --check`: 통과. 화면 변경이 없어 브라우저 캡처는 추가하지 않았다.
실제 DB·브로커·Keycloak 검증은 사용자 보류 상태다.
레거시 Supabase 빌드·E2E 실패 면제를 유지하며 재실행하지 않는다.

## 남은 일

UI-5 종목부터 UI-10 최종 디자인 검수까지 순차 진행한다.
새 함수를 실제 화면에 연결하는 일은 다음 단계의 범위다.
기존 저장 기능의 새 서비스 이관 및 클라우드 환경 구성은 디자인 완료 후 별도 진행한다.
